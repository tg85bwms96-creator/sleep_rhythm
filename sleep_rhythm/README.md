# 리듬 · RHYTHM v2.2

자기 전에 **잠자러 가기**, 일어나서 **일어났어요**만 누르면 수면이 기록되고, 내일 집중할 교시를 고르면 **오늘 밤 잠들 시각**을 계산해 주는 Python 수면 플래너입니다. 휴대폰에서 쓰도록 만든 웹앱(PWA)이며, 컴퓨터 브라우저에서도 같은 화면이 열립니다.

**사용 방법과 배포 절차는 [START_HERE_KO.md](START_HERE_KO.md)를 보세요.**

```bash
python run.py                   # 로컬 실행: http://127.0.0.1:8000 (Python 3.11 이상, 추가 설치 없음)
python run.py --host 0.0.0.0    # 같은 Wi-Fi의 휴대폰으로 시험: 실행 창에 휴대폰에서 열 주소가 나옴
```

| 탭 | 내용 |
|---|---|
| 시작 안내 | 앱을 열 때마다 사용법과 어려운 말 풀이(수면압, 일주기 기준, AL, 모형 각성도 등). **닫기** / **이 창 재접속까지 보지 않기** |
| 홈 | 한 화면(스크롤 없음): 취침 시각 계산 버튼과 결과 → 나의 기록 상태 → 내일 언제 집중할까요?(1~7교시·방과후, 설정에서 8·9교시 추가) → 잠자러 가기 → 꼭 일어나야 하는 시각 |
| 수면 기록 | 버튼 기록, 놓친 날 직접 추가, 고치기·지우기. 앱을 켜 둔 채 자면 잠금을 풀 때 일어난 시각을 먼저 물어봄 |
| 분석 | 최근 7·14일 수면시간, 권장량 충족, 자고 일어나는 시각의 규칙성, 평일·주말 차이, 모형상 필요 수면, 낮잠, 아침 졸림을 쉬운 말로 해설. 14일 막대 그래프, 수업 중 졸림 기록과 모델 A·B·C 비교 |
| 계산 근거 | 최근 계산의 조건 확인, 평소 습관과 비교, 24시간 S·C·AL 그래프, 모든 후보, 가정 변화, 계산 방법·용어·한계 |
| 설정 | 연령대·생활 유형·시간대, 학교 시간표(교시 시각, 8·9교시 추가·빼기, 저장 전 바뀐 내용 표시), 백업·복원·CSV·삭제, 14일 예시 |

수리 모형은 수면압 S(지수식), 일주기 수면 기준 C(개인 위상), 각성 지표 AL = C − S입니다. 연령별 최소 수면을 반드시 지키고, 고른 교시 내내 AL ≥ 0이 되도록 하면서 평소 취침 시각을 가장 적게 바꾸는 시각을 고릅니다. 수면 연구의 수면압·일주기 개념을 참고해 새로 만든 교육·자기관리용 모형이며, 연구의 모형·코드·정확도를 재현하거나 의료 진단을 제공하지 않습니다.

모든 버튼은 누르는 순간 반응하고 잠깐 빛나며, 고르는 버튼은 선택된 동안 색이 채워진 채로 유지됩니다.

## 프로젝트 구성

```text
run.py                  로컬·생산용 실행 진입점 (--production = Waitress)
start_windows.bat       Windows 더블클릭 실행 (start_windows_phone.bat = 같은 Wi-Fi 휴대폰 시험용)
start_macos.command     macOS 실행
sleepapp/model.py       입력 검증, 수면압·일주기 모형, 교시 구간·자동 범위 추천, 모델 비교
sleepapp/analysis.py    수면 기록 분석과 해설
sleepapp/server.py      상태를 저장하지 않는 WSGI 서버(정적 파일 + JSON API)
web/                    휴대폰 화면, 수면 측정, PWA(오프라인 실행), 그래프, 브라우저 저장
tests/                  모형·분석·서버·화면 보조 함수 테스트
docs/MODEL.md           식, 가정, 판정 규칙, 분석 계산, 계획서와의 대응
docs/VERIFICATION.md    실제 확인한 범위와 확인하지 못한 범위
docs/TEST_RESULTS.txt   최종 테스트 실행 출력
render.yaml             Render Blueprint (무료 웹 서비스)
.python-version         배포 Python 버전(3.13)
Dockerfile              선택: 컨테이너 배포
requirements.txt        생산 서버(waitress)·시간대 데이터(tzdata)
```

## 테스트

```bash
python -m unittest discover -s tests -v     # Python 모형·분석·서버·실행기 테스트
node --test tests/test_utils.mjs            # 브라우저 보조 함수 테스트(Node.js 22에서 확인)
```

Node.js는 테스트에만 필요하며 앱 실행에는 필요하지 않습니다. 실제 수면 자료나 탐구 결과는 패키지에 포함하지 않았습니다.
